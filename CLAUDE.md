# StarShelf — public repo

This is the **public-facing** repo for StarShelf, a sci-fi award book tracker. It also hosts
the book cover images, served over GitHub Pages:

```
https://al-campuzano.github.io/starshelf-alpha/covers/[book_id].jpg
```

## The app code is somewhere else

**The working repo is `~/sci-fi-book-app`** (`Al-Campuzano/sci-fi-book-app`) — that's where
the app code and the FlutterFlow workspace live, and where nearly all the work happens. If
you've been asked to change how the app behaves, you are probably in the wrong directory.

## Project notes live in the dev-notes vault

What's left to do, why things were built this way, and how features work are all in the
Obsidian vault at `~/Documents/dev-notes-vault` (private repo `Al-Campuzano/dev-notes-vault`),
under `StarShelf (book app)/`.

**Start with `StarShelf (book app)/_context_StarShelf.md`.** The to-do list of record is
`StarShelf (book app)/StarShelf TO-DO.md` — not a TODO file in this repo, and not a checklist
in a commit message.

Read the vault's own `CLAUDE.md` before writing into it. Don't copy vault content into this
repo; two copies of a to-do list is how both rot.
